# Cloud Retail Analytics Platform

## Overview

End-to-end cloud analytics platform for retail sales analytics and forecasting.

The project demonstrates a modern data stack using AWS services, Snowflake, dbt, Airflow, and Machine Learning.

---

## Architecture

AWS S3 → AWS Glue → Snowflake → dbt → MLflow → Power BI

---

## Tech Stack

### Cloud
- AWS S3
- AWS Glue
- AWS Athena
- AWS IAM

### Data Engineering
- Snowflake
- dbt
- Airflow
- Python

### Machine Learning
- Scikit-learn
- XGBoost
- MLflow

### Visualization
- Power BI
